# Monthly Report Assembly

A hands-on exercise for learning Claude Code / Cowork: assemble a monthly portfolio
performance report from raw property exports, the way an asset management team would.

All data here is entirely fictional. Property names, unit counts, rents, occupancy,
and NOI figures are invented for teaching purposes and do not represent any real
company, property, or market.

## The exercise

`inputs/` has two months of an 8-property CSV export. `reference/` has last month's
finished report, the format to match. Ask Claude to produce the August report in the
same format, using both CSVs. The interesting findings are in the data itself; they
are not labeled anywhere, so look for them in the numbers.
