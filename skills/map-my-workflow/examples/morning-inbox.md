# Example: the morning inbox

A finished map, fictional. Use it to see the shape, not the content.

```
Workflow: Morning inbox replies
Feeds: same-day answers to clients and the team, for me

Today: 4 steps, about 75 minutes every weekday
  1. Open Outlook, scroll the inbox top to bottom.        Outlook   ~10 min
     "I basically read everything twice." (call, Oct 12)
  2. Open each email, one at a time.                      Outlook   ~1 min each
  3. Copy it into Claude, ask for a reply, paste it back.  Claude    ~2 min each
     "I keep re-explaining who the person is." (team check-in, Oct 20)
  4. Fix the tone, send, repeat.                          Outlook   ~1 min each
Worst steps: 3, the copy-paste loop and re-explaining context every time.

Should be: 4 steps
  1. New mail -> a 7 AM scan groups it by person and project -> one list   [black and white]
  2. My voice note -> read before drafting -> tone rules in hand           [black and white]
  3. Each email that needs a reply -> draft a reply -> drafts on one page  [gray]
  4. Drafts page -> I edit and send                                        [human]

Build: a scheduled task that runs the write-in-my-voice skill, because the work
starts on a clock and the drafting is already a skill.
Must tie out: every new email appears in exactly one group; no draft is sent
without my go.
First move: run step 3 alone on yesterday's inbox and compare the drafts with
what I actually sent.
Sources: Oct 12 call summary, Oct 20 check-in summary, five sent emails.
```
