# improvements.md

The inbox. improve appends one block per skill, dated. The user works it on a cadence, weekly to start: read a block, apply it to the skill if it is right, delete the block or leave it.

One block per skill each time improve runs. If several promoted learnings touch the same skill, they share one block as stacked evidence.

## YYYY-MM-DD: <skill or file the change touches>

**Change.** One or two sentences: what to add or edit in the skill.

**Reason.** Why the change earns its place in the skill.

**Evidence.** The promoted learnings behind it, with their dates.
- 2026-09-17 15:10: <learning>. <the evidence that promoted it>.
